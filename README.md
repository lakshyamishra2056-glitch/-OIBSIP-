## 🚀 How to Run

1. Clone the repository
   ```bash
   git clone https://github.com/lakshyamishra2056-glitch/-OIBSIP-.git
   cd -OIBSIP-
   ```
2. Install the required libraries
   ```bash
   pip install pandas numpy matplotlib seaborn jupyter
   ```
3. Launch Jupyter Notebook and open the task notebook
   ```bash
   jupyter notebook lakshya_task2.ipynb
   ```
